API ENDPOINTS SPECIFICATION
================================================================================

1. GET /api/requests/provider/pending/
   Authentication: Required (provider user)
   Parameters:
     - service_type (optional)
     - max_distance_km (default: 50)
     - include_urgent_only (default: false)
     - limit (default: 50, max: 200)
   Response: List of requests sorted by priority_score

2. GET /api/requests/{id}/priority-details/
   Authentication: Required (provider user)
   Parameters: None
   Response: Priority score breakdown

3. GET /api/requests/providers-nearby/
   Authentication: Not required
   Parameters:
     - latitude (required)
     - longitude (required)
     - max_distance_km (default: 50)
     - service_type (optional)
   Response: List of providers within radius

================================================================================
PRIORITY SCORE FORMULA
================================================================================

Priority Score = Urgent Bonus + Distance Bonus + Time Bonus

Where:
  - Urgent Bonus = 100 if urgent else 0
  - Distance Bonus = max(0, 50 - distance_km) capped at 50
  - Time Bonus = min(30, hours_old * 2) capped at 30
  - Total Range: 0-180 points

Priority Tiers:
  - HIGHEST: 140-180 (Urgent + Close)
  - HIGH: 100-139 (Urgent or Old)
  - MEDIUM: 50-99 (Regular + Close)
  - LOW: 0-49 (Regular + Far)

================================================================================
HAVERSINE FORMULA
================================================================================

Formula:
  d = 2R × arcsin(√(sin²((φ₂-φ₁)/2) + cos(φ₁) × cos(φ₂) × sin²((λ₂-λ₁)/2)))

Where:
  - R = 6371 km (Earth's radius)
  - φ = Latitude (in radians)
  - λ = Longitude (in radians)
  - d = Distance in kilometers

Output: Rounded to 1 decimal place

Distance Display Format:
  - < 1 km: Display in meters (e.g., "450m away")
  - ≥ 1 km: Display in km (e.g., "2.5 km away")
  - None: "Distance not available"
