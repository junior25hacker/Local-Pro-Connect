================================================================================
DATA FLOW DIAGRAM
================================================================================

USER INPUT (Frontend)
    │
    ├─ Emergency Type (radio selection)
    ├─ Description (textarea)
    ├─ Phone (text input)
    ├─ Location (geolocation API or manual text input)
    └─ Provider Selection (radio selection)
         │
         ↓
VALIDATION (Frontend JavaScript)
    │
    ├─ All required fields filled?
    ├─ Valid emergency type?
    ├─ Valid phone format?
    ├─ Location available (geolocation OR manual address)?
    ├─ Provider selected?
    └─ Submit button enabled?
         │
         ↓
FORM SUBMISSION (AJAX)
    │
    ├─ POST /accounts/emergency/
    ├─ Include CSRF token
    └─ Form data: emergency_type, description, phone, location_lat, 
               location_lng, address, manual_address, selected_provider
         │
         ↓
BACKEND PROCESSING (Django View)
    │
    ├─ Validate authentication (@login_required)
    ├─ Validate all required fields
    ├─ Validate location (geolocation OR manual)
    ├─ Fetch provider from database
    ├─ Fetch provider profile
    ├─ Create ServiceRequest with:
    │  ├─ urgent = True
    │  ├─ status = 'pending'
    │  ├─ description = description + location info
    │  └─ user = current user
    ├─ Update UserProfile phone if empty
    ├─ Send email to provider
    └─ Mark email as sent
         │
         ↓
DATABASE STORAGE
    │
    ├─ ServiceRequest record created
    ├─ Set urgent = True
    ├─ All location info in description
    └─ Email tracking fields updated
         │
         ↓
PROVIDER NOTIFICATION
    │
    ├─ Email sent to provider
    ├─ Email includes:
    │  ├─ Customer contact info
    │  ├─ Emergency type
    │  ├─ Location (if geolocation: coordinates; if manual: address text)
    │  └─ Request detail link
    └─ Provider can view in dashboard
         │
         ↓
USER CONFIRMATION
    │
    ├─ Success message shown
    ├─ Request ID returned
    └─ Redirect to user profile
